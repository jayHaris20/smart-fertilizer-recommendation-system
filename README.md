# 🌱 Smart Fertilizer Recommendation System

## Project Overview
A Machine Learning-based web application that recommends suitable fertilizers based on agricultural input data.

## Features
- Smart fertilizer recommendations
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Machine Learning model
- Flask web application

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Matplotlib
- Seaborn

## Project Structure
- `main.py` – Application entry point
- `app/` – Application files
- `fertilizer_recommendation_dataset.csv` – Dataset
- `fertilizer_model.pkl` – Trained ML model

## Installation

```bash
git clone https://github.com/jayHaris20/smart-fertilizer-recommendation-system.git
cd smart-fertilizer-recommendation-system
pip install -r requirements.txt
python main.py
```
