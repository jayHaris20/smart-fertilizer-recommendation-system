# 🌱 Smart Fertilizer Recommendation System

## 📌 Project Overview
Smart Fertilizer Recommendation System is a Machine Learning-based web application designed to recommend suitable fertilizers based on agricultural input data.

The system uses a trained ML model to generate fertilizer recommendations through a simple Flask web interface.

## ✨ Features
- Machine Learning-based fertilizer recommendations
- Data preprocessing and exploratory data analysis (EDA)
- Trained ML model
- Feature encoding and StandardScaler
- Interactive web application using Flask

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Matplotlib / Seaborn

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/jayHaris20/smart-fertilizer-recommendation-system.git
```

2. Navigate to the project folder:

```bash
cd smart-fertilizer-recommendation-system
```

3. Install dependencies:

```bash
pip install pandas numpy scikit-learn flask matplotlib seaborn
```

4. Run the application:

```bash
python main.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000/
```

## 🎯 Project Objective

To demonstrate how Machine Learning can support agricultural decision-making by providing fertilizer recommendations through an easy-to-use web application.
